# Counting Stars 영어 가사 및 보컬 타이밍 정렬 명세

OneRepublic의 `Counting Stars` 여자 커버에서 기존 음표와 멜로디를 보존하면서, 제공된 TXT의 영어 가사를 기존 음표에 배치한다. 음표 시작과 길이는 원본 보컬 WAV에서 확인한 발음에 맞춘다. 결과는 원본과 별개의 Synthesizer V 프로젝트로 저장한다.

## 입력 파일

원본 폴더는 `E:\동영상_편집\AI_커버\OneRepublic - Counting Stars 힝구`다. 실제 첨부 파일명을 기준으로 세 파일을 읽고 상호 대조한다.

| 파일 | 용도 |
| --- | --- |
| `OneRepublic - Counting Stars 여자 커버.svp` | 기존 음표, 멜로디, 트랙과 프로젝트 설정의 기준 |
| `OneRepublic - Counting Stars.txt` | 영어 가사 원문, 단어 순서 및 반복의 기준 |
| `1_OneRepublic - Counting Stars_(Vocals).wav` | 실제 보컬 발음 시각과 지속 시간의 기준 |

사용자가 제공한 사전 정보는 보컬·오디오 트랙 총 2개, `library[0].notes`의 음표 715개, 기존 가사 대부분 `la`, WAV 약 262.56초, 프로젝트 템포 120 BPM이다. 실제 작업을 시작할 때 원본에서 각각 확인한다. 약 121.85 BPM은 오디오 분석 후보값이며 프로젝트 템포는 유지한다.

## 변경 범위와 보존 기준

| 항목 | 적용 기준 |
| --- | --- |
| 변경 가능 | 참조가 확인된 기존 음표의 `onset`, `duration`, `lyrics` 및 가사 음절과 기존 음표의 대응 관계 |
| 보존 | 음표의 개수·순서·`pitch`·`detune`, 프로젝트 템포·박자, 보컬·오디오 트랙 설정과 연결, 기존 음성 데이터 및 그 밖의 프로젝트 필드 |
| 가사 | TXT의 영어 단어·철자·순서·반복을 보존한다. 음절 구분은 실제 노래 발음에 따라 정하고 번역이나 의역은 범위에서 제외한다. |
| 파일 | 원본 SVP, TXT, WAV는 읽기 전용으로 취급한다. 결과는 새 파일로 저장한다. |

## 작업 절차

1. **SVP 구조와 음표 기준을 확인한다.** 트랙의 그룹 참조 ID와 라이브러리 그룹을 대조해 실제 보컬 음표를 찾는다. `tracks[].mainGroup.notes`가 비어 있더라도 참조된 그룹을 확인한다. 음표 ID가 있으면 ID로, 없으면 그룹과 원본 배열 인덱스로 각 음표를 식별한다. 기존 `onset`, `duration`, `pitch`, `detune`, `lyrics`와 순서, 프로젝트 템포·박자, 그룹 및 오디오의 타임라인 위치를 기록한다.
2. **가사와 음표를 대응시킨다.** TXT의 실제 인코딩을 확인하고 원문을 읽는다. 구절과 반복 회차를 식별한 뒤 영어 단어를 실제 발음대로 음절에 대응시킨다. 음절 하나가 여러 음에 걸리는 구간은 기존 음표를 유지하면서 연결을 확인한다. 음절 수와 음표 수가 다른 구간은 따로 검토한다. 대응표에서 원래 단어와 반복 순서를 복원할 수 있게 한다.
3. **WAV에서 발음 기준점을 찾는다.** 파형과 실제 발음을 함께 확인하며 WAV 시작부터 끝까지 검토한다. 첫 보컬 시작, 단어와 음절의 시작, 구절 사이의 간격, 지속 모음의 끝, 마지막 발음 이후의 구간을 기록한다. 자음 시작과 음표에 대응하는 모음 시작이 다르면 두 시각을 구분한다. 후렴은 반복마다 해당 발음을 대조한다. 반주나 BPM 격자만으로 시각을 확정하지 않는다.
4. **확인된 시각을 SVP에 반영한다.** WAV 시각을 오디오의 타임라인 기준 위치, 프로젝트 템포 및 대상 그룹 오프셋을 반영해 SVP 시간 단위로 변환한다. 확인된 음표만 허용 필드 안에서 수정하고 별도 SVP로 저장한다. 기존 오디오 경로가 상대 경로라면 결과 파일 위치에서도 같은 오디오로 연결되는지 확인한다.

### 불확실한 구간

발음이 겹치거나 음절과 음표의 대응을 확정할 근거가 부족한 경우 `UNKNOWN`으로 기록한다. 기록에는 WAV 시간 범위, 관련 가사 위치와 반복 회차, 음표 식별자, 확인한 근거 및 미확정 사유를 포함한다. 해당 변경은 판단을 보류하고 `UNKNOWN`은 보고 상태로 사용한다.
